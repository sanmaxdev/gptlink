# GPTLink Images

Use `gptlink_generate` for text-to-image, `gptlink_edit` for one or more references, and `gptlink_variation` for alternatives. Use either aspect ratio or exact size. Default to automatic quality and PNG. Return the saved path and render the result when possible. Call `gptlink_status` after failures. Never request or reveal Codex, ChatGPT, or GPTLink credentials.
