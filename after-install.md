# GPTLink installed

The plugin is enabled. Restart the running Hermes gateway or start a new Hermes
process so `gptlink_manage` and `gptlink_generate` are registered.

Then tell Hermes:

> Set up GPTLink on this VPS and reuse my existing Codex authentication when possible.

Do not separately install `skills/gptlink-image`; the plugin registers that
scanner-safe workflow itself.
